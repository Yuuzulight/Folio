# Folio 0.9.0 (pre-release)

## What Folio is

Folio is a lightweight HTML/CSS rendering engine for .NET, written from scratch in C#. It renders and runs AI-written
HTML artifacts (reports, tables, charts, small interactive pages) inside a host application's own window.

## What's included

- Packages: `Folio` (portable static rendering), `Folio.Diagrams`, `Folio.Scripting` and `Folio.WinForms` (the Windows
  control), all version 0.9.0, as `.nupkg` files.
- `Folio.ContentHost-0.9.0-win-x64.zip`: the NativeAOT content host that runs page scripts in a separate process. Extract
  and deploy the whole directory, including `fonts`.
- `SHA256SUMS.txt`.

## Supported

- Static HTML/CSS rendering, text, SVG and images, headless render to PNG, with bundled fonts.
- Interaction in the Windows control: hover, clicks, scrolling, text selection and relayout on resize.
- Scripting with the Folio-owned JavaScript engine, run in a sandboxed content process with strict limits.
- Pinned libraries from the tested scripting and canvas corpus. TODO: list the pinned libraries and versions.
- Canvas graphics.
- Diagrams (`Folio.Diagrams`).

Advanced APIs have narrower support than a general-purpose browser; see the
[consumer readiness audit](../consumer-readiness-audit.md). Folio is not a general-purpose browser.

## Features off by default

Every capability grant in `FolioOptions.Capabilities` defaults to `false` and must be granted by the host
([host feature capabilities](../feature-capabilities.md)).

Remote WebRTC is behind the `WebRtc` capability, which is off by default. Sandboxed UDP routing, TURN relay and remote
media are not complete. TODO: confirm this wording against the open WebRTC issues at release time.

## Requirements

- .NET 10 (SDK 10.0.403 or newer to build; the packages target `net10.0`).
- Windows for the content host and the WinForms control (`net10.0-windows`). The portable `Folio` and `Folio.Diagrams`
  static rendering also runs on Linux.
