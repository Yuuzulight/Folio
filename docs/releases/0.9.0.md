# Folio 0.9.0 (pre-release)

## What Folio is

Folio is a lightweight HTML/CSS rendering engine for .NET, written from scratch in C#. It renders and runs AI-written
HTML artifacts (reports, tables, charts, small interactive pages) inside a host application's own window.

## What's included

- Packages: `Folio` (portable static rendering), `Folio.Diagrams`, `Folio.Scripting` and `Folio.WinForms` (the Windows
  control), all version 0.9.0, as `.nupkg` files.
- `Folio.ContentHost-0.9.0-win-x64.zip`: the NativeAOT content host that runs page scripts in a separate process. Extract
  and deploy the whole directory, including `fonts`.
- `SHA256SUMS.txt`.

## Supported

- Static HTML/CSS rendering, text, SVG and images, headless render to PNG, with bundled fonts.
- Interaction in the Windows control: hover, clicks, scrolling, text selection and relayout on resize.
- Scripting with the Folio-owned JavaScript engine, run in a sandboxed content process with strict limits.
- Pinned libraries from the tested scripting and canvas corpus: React 18.3.1 with Babel Standalone 7.26.4, Twind 0.16.19, D3 7.9.0, Chart.js 4.4.7, Mermaid 11.4.1 and Phaser 3.90.0.
- Canvas graphics.
- Diagrams (`Folio.Diagrams`).

Advanced APIs have narrower support than a general-purpose browser; see the
[consumer readiness audit](../consumer-readiness-audit.md). Folio is not a general-purpose browser.

## Known limits in this pre-release

Measured on an AMD Ryzen 7 5800X (8 cores), Windows 11 (10.0.26300), .NET SDK 10.0.403, on 2026-11-13, at commit
`f452490d30c42ace16fb278cc1fbb8f7ddcc96aa` of `main` plus three unmerged benchmark-only branches
(`test/frame-benchmarks-steady-state`, `test/library-startup-benchmark`, `test/canvas-frames-native-aot`; no engine
changes). Figures are the median of the runs' medians, with the range in brackets.

- Paint budgets: warmed-up JIT inside the host application, 3 runs (5 warm-ups, 30 frames each).
- Scripted start-up, library start-up and script-driven canvas frames: the published NativeAOT content host. Scripted
  and library start-up are 2 runs each. The canvas figure is one run of the probe, which itself takes the median of 4
  runs of 30 frames.
- Machine load: the paint runs were on a quiet machine. For the start-up runs the machine was not fully quiet (RAM use
  85 to 89%, no other benchmark processes), and the second scripted run was visibly slower than the first, so treat
  those figures as upper-end.

against the current single 50 ms / 80 MiB limit. The JIT canvas-frame figures were not measured for this release.

## Requirements

- .NET 10 (SDK 10.0.403 or newer to build; the packages target `net10.0`).
- Windows for the content host and the WinForms control (`net10.0-windows`). The portable `Folio` and `Folio.Diagrams`
  static rendering also runs on Linux.
