# Custom elements and shadow DOM survey

The M5 conformance corpus was searched on 2026-10-16 for `customElements`, `attachShadow`, and `shadowRoot` in artifact HTML and scripts. No artifact uses these APIs.

The corpus therefore does not justify adding custom-element upgrades, shadow trees, slotting, or the associated styling and event rules to M5. The issue remains a future compatibility item; it should be reopened if a required library artifact introduces one of these APIs.
