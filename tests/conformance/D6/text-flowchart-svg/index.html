Order pipeline

Each diagram below is written as plain text. A small script reads the text and draws the flowchart.

Checkout

Start -> Validate -> Save
Validate -> Reject : invalid
Save -> Notify -> End
Reject -> End

Refund request

Start -> Lookup order -> Check window
Check window -> Approve : within 30 days
Check window -> Escalate : late
Escalate -> Approve : manager ok
Escalate -> Decline
Approve -> Issue refund -> End
Decline -> End
