5.3.0

Latest 24 September 2026

This release introduces linked blocks, which let you embed a paragraph from one note in another and keep both copies in sync. It also replaces the search index, which is now about four times faster on vaults with more than 10,000 notes.

Added

  • Linked blocks: type (( to search for a block and embed it. #2214
  • New command palette action, Copy block link, bound to Ctrl+Shift+L.
  • Search now supports tag: and before: filters, for example tag:recipes before:2026-01-01.

Changed

  • The search index is rebuilt on first launch after updating. On a large vault this takes 1–3 minutes and runs in the background.
  • Daily notes now open at the end of the note instead of the start.
Breaking change: the old search.legacyIndex setting has been removed. If you had it enabled, it is ignored and the new index is used.

Fixed

  • Pasting a table from a spreadsheet no longer drops the last column. #2190
  • Fixed a crash when renaming a note that was open in two windows. #2231
  • Undo after Ctrl+D (duplicate line) now restores the cursor position.
Show 14 smaller fixes
  • Corrected the word count for text containing em dashes.
  • Fixed the outline panel flickering while typing a heading.
  • Improved contrast of placeholder text in dark themes.
  • Checkbox state is now preserved when moving a list item with Alt+↑.
  • Fixed tooltips appearing off-screen near the right side of the window.
  • And nine more minor layout fixes.

5.2.0

2 September 2026

Our most requested feature: proper tables, with keyboard navigation and column resizing.

Added

Tables

  • Insert a table with /table, or by pasting tab-separated text.
  • Move between cells with Tab and Shift+Tab.
    • Pressing Tab in the last cell adds a new row.
    • Pressing Enter inside a cell inserts a line break.
  • Drag a column border to resize it; double-click to fit the content.

Export

  • Export a single note as a standalone HTML file.

Removed

  • The experimental "focus lens" view, which fewer than 0.5% of people used.

5.1.2

11 August 2026

A patch release focused on sync.

Fixed

  • Resolved a rare case where two devices editing the same note offline would each keep only their own changes. Conflicting edits are now merged, and a conflict tag is added when a merge is not possible.
  • Sync no longer stalls when a note's title contains a trailing space.
  • Reduced memory use during the initial sync of large vaults by about 35%.
