Shipments

Create, track and cancel shipments. A shipment represents one parcel travelling from a sender to a recipient with a single carrier.

  • POST Create a shipment
  • The shipment object
  • GET Retrieve a shipment

Authentication

Every request must include your secret key in the Authorization header as a bearer token. Keys starting with pp_test_ work only in the sandbox; keys starting with pp_live_ create real shipments and incur charges. 

GET /v3/shipments/shp_8KqT2mZ HTTP/1.1
Host: api.parcelpoint.example
Authorization: Bearer pp_test_<your key>
Accept: application/json
Never embed a live key in client-side code or a mobile app. Anyone who has the key can create shipments billed to your account.

The shipment object

FieldDescription
id
string		Unique identifier, prefixed with shp_.
status
enum		One of created, label_ready, in_transit, delivered, cancelled.
carrier
string		Carrier code, for example swiftpost.
weight_g
integer		Parcel weight in grams.
tracking_number
string | null		Set once a label is generated.
created_at
timestamp		ISO 8601 timestamp in UTC.

Create a shipment

POST /v3/shipments

Creates a shipment and, if buy_label is true, purchases a shipping label immediately.

Body parameters

NameDescription
from required
address		Sender address. See the address guide for the required fields per country.
to required
address		Recipient address.
weight_g required
integer		Weight in grams, between 1 and 30,000.
carrier
string		Carrier code. If omitted, we choose the cheapest carrier that meets service_level.
service_level
enum		economy, standard (default) or express.
buy_label
boolean		Defaults to false.

Example request

{
  "from": { "postcode": "EH1 1YZ", "country": "GB" },
  "to":   { "postcode": "M1 4BT",  "country": "GB" },
  "weight_g": 1250,
  "service_level": "standard",
  "buy_label": true
}

Example response

{
  "id": "shp_8KqT2mZ",
  "status": "label_ready",
  "carrier": "swiftpost",
  "weight_g": 1250,
  "price": { "amount": 4.85, "currency": "GBP" },
  "tracking_number": "SP4410982273GB",
  "cancelled_at": null,
  "created_at": "2026-09-18T10:42:07Z"
}
Requests are idempotent if you send an Idempotency-Key header. Retrying with the same key within 24 hours returns the original shipment instead of creating a second one.

Retrieve a shipment

GET /v3/shipments/{id}

Returns the shipment object. Tracking updates are reflected in status within about two minutes of the carrier reporting them.

Cancel a shipment

DELETE /v3/shipments/{id}

Cancels the shipment and refunds the label cost. Only shipments with status created or label_ready can be cancelled. Once the carrier has scanned the parcel, cancellation returns a 409.

Errors

Errors use standard HTTP status codes and return a body with a machine-readable code and a human-readable message.

400
The request body is malformed or a parameter is out of range.
401
The API key is missing, revoked, or for the wrong environment.
404
No shipment exists with that ID on your account.
409
The shipment is in a state that does not allow this action.
429
Too many requests. The limit is 100 requests per second per key; see the Retry-After header.
