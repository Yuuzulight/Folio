Postmortem: Ledger API outage caused by an expired TLS certificate

Date14 March
Duration41 minutes
SeveritySEV-2
AuthorPriya Raman
Summary. From 09:12 to 09:53 UTC, every request to api.ledgerline.example failed the TLS handshake because the certificate on the public load balancer expired. Roughly 18,400 customer requests were rejected. No data was lost or corrupted.

Impact

All third-party integrations that call the Ledger API directly saw connection errors for the full window. The web dashboard stayed up because it talks to an internal endpoint with a separately managed certificate, but its Export and Sync now buttons failed, since they proxy through the public API.

  • 312 customer accounts affected, 41 of them on the Enterprise plan.
  • Nightly reconciliation jobs for 6 partners were delayed by up to 2 hours.
  • Support received 57 tickets; the status page was updated 11 minutes after the first alert.

Root cause

The certificate was supposed to renew automatically 30 days before expiry. The renewal job had been failing silently since 19 February, when a DNS cleanup removed the _acme-challenge TXT record it depends on. The job logged each failure at INFO level and exited with status 0, so nothing alerted.

The renewal job configuration

# cert-renewer.yaml (before the fix)
domain: api.ledgerline.example
renew_before_days: 30
validation: dns
on_failure:
  log_level: info      # should have been "error"
  exit_code: 0          # masked the failure from the scheduler

Why it was not caught earlier

We had an expiry monitor, but it only covered certificates listed in the internal inventory. The public load balancer was provisioned by hand in 2023 and never added to that list.

What went well

  • The synthetic check caught the problem within two minutes.
  • The dashboard kept serving read-only views, which reduced ticket volume.

Action items

  1. Make the renewal job exit non-zero and log at error on failure. Tomás
  2. Add every public endpoint to the certificate inventory, and alert at 21 and 7 days before expiry. Priya
  3. Protect _acme-challenge records from bulk DNS cleanups. Infra
  4. Add a runbook entry for inspecting a TLS handshake. Tomás
