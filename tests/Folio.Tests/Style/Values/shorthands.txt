=== background color only
background: #f00
---
background-color: rgb(255, 0, 0)
background-image: none
background-position: 0px 0px
background-repeat: repeat

=== background with image, position, size and repeat
background: url(a.png) right 10px bottom / cover no-repeat fixed content-box
---
background-image: url("a.png")
background-position: -10px + 100% 100%
background-size: cover
background-repeat: no-repeat
background-attachment: fixed
background-origin: content-box
background-clip: content-box

=== two boxes set origin then clip
background: padding-box border-box red
---
background-origin: padding-box
background-clip: border-box
background-color: rgb(255, 0, 0)

=== multiple layers with the colour last
background: url(top.png) no-repeat, linear-gradient(red, blue) #00f
---
background-image: url("top.png"), linear-gradient(red, blue)
background-repeat: no-repeat, repeat
background-color: rgb(0, 0, 255)

=== the colour only in the last layer
background: red, url(x.png)
---
background-color: rgba(0, 0, 0, 0)
background-image: none

=== border-radius expands to the four corners
border-radius: 10px 20% 5px
---
border-top-left-radius: 10px
border-top-right-radius: 20%
border-bottom-right-radius: 5px
border-bottom-left-radius: 20%

=== border-radius with vertical radii after a slash
border-radius: 10px 20px / 5px
---
border-top-left-radius: 10px 5px
border-top-right-radius: 20px 5px
border-bottom-right-radius: 10px 5px
border-bottom-left-radius: 20px 5px

=== border-radius rejects negative radii and a slash without vertical radii
border-radius: 10px; border-radius: -1px; border-top-left-radius: 1px / 2px
---
border-top-left-radius: 10px
border-top-right-radius: 10px

=== grid track lists with repeat, names and sizing functions

grid-template-rows: minmax(10px, 1fr) fit-content(50%) 2fr auto
