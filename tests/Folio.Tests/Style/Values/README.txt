Computed value cases, written from CSS Values 4, Color 4, Fonts 4, Box/Backgrounds and the property definitions.

Format: "=== name", optional "%parent <declarations>" (the parent's style; its parent has initial values),
the element's declarations (a style attribute's contents), "---", then "property: computed value" lines.
Only the properties listed are checked. The viewport is 800x600 and the root font size 16px.
