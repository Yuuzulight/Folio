=== all unset removes button defaults and inherits text properties
<!DOCTYPE html><style>div { color: green; font-size: 20px } button { all: unset }</style><div><button id=a>x</button></div>
---
#a display: inline
#a color: rgb(0, 128, 0)
#a font-size: 20
#a padding-left: 0px
#a border-top-style: none
#a text-align: start
