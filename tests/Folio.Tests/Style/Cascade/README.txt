Cascade cases, written from CSS Cascade 5, Variables 1, Nesting 1, Media Queries 4, Conditional 3 and the HTML
standard's Rendering section (for the user-agent stylesheet).

Format: "=== name", optional "%viewport <width> <height>" (default 800 600) and "%dark", the HTML document,
"---", then "<element> <property>: <computed value>" lines, where <element> is "#id" or the first element with
that tag name.
A "--name" property line checks a custom property's computed text ("none" when it has no value).
