=== before and after with counters and attr
<!DOCTYPE html><style>h2 { counter-increment: sec } h2::before { content: counter(sec) ". " } p::after { content: " [" attr(data-x) "]" }</style><h2>A</h2><h2>B</h2><p data-x=1>t</p>
---
block html
  block body
    block h2
      <::before>
      "1. "
      </::before>
      "A"
    block h2
      <::before>
      "2. "
      </::before>
      "B"
    block p
      "t"
      <::after>
      " [1]"
      </::after>

=== pseudo-elements without content generate nothing
<!DOCTYPE html><style>p::before { color: red } p::after { content: none }</style><p>t</p>
---

  block body
    block p
      "t"
