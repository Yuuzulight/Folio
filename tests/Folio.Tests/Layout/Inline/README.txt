Inline layout cases, written from CSS 2.2 sections 9.4.2 (inline formatting contexts), 10.8 (line height), CSS Text 3
(white space, line breaking, text-align) and CSS Inline 3, with the Unicode line breaking algorithm (UAX #14).

Text is set in the test box font (tests/fonts/FolioBox.ttf) for every family: each character is one em wide, with an
ascent of 0.8em, a descent of 0.2em and a normal line height of 1em (16px at the initial font size).

Format: as in ../Block/README.txt, plus "line" for line boxes and text "..." for runs of text, placed in page
coordinates; inline boxes appear on each line they cross, before the text.
