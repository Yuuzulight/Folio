=== a length raises an inline box and the line grows to fit it
<!DOCTYPE html><style>body, p { margin: 0 }</style><p>a<span style="vertical-align: 4px">b</span></p>
---
html 0,0 800x20
  body 0,0 800x20
    p 0,0 800x20
      line 0,0 800x20
        span 16,0 16x16
        text "a" 0,4 16x16
        text "b" 16,0 16x16

=== super raises the baseline by a third of the parent's font size plus a pixel, and sub and sup keep the inherited line height
<!DOCTYPE html><style>body, p { margin: 0 } p { line-height: 1.5 }</style><p>a<sup>b</sup>c<sub>d</sub></p>
---
html 0,0 800x30.52
  body 0,0 800x30.52
    p 0,0 800x30.52
      line 0,0 800x30.52
        sup 16,2 13.33x14
        sub 45.33,12.53 13.33x14
        text "a" 0,6.33 16x16
        text "b" 16,2 13.33x14
        text "c" 29.33,6.33 16x16
        text "d" 45.33,12.53 13.33x14
