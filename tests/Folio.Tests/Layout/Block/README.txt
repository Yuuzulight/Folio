Block layout cases, written from CSS 2.2 sections 8.3.1 (collapsing margins), 10.3.3 (block-level widths), 10.4
(min/max widths), 10.5 and 10.6.3 (heights) and 10.7 (min/max heights), and CSS Box Sizing 3.

Format: "=== name", optional "%viewport <width> <height>" (default 800 600), the HTML document, "---", then the
fragment tree from the root element: one fragment per line as "<element>[#id] <x>,<y> <width>x<height>", the border
box in page coordinates, children indented two spaces.
