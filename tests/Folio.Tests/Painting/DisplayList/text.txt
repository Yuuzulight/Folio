=== text is painted in its box's colour, glyph by glyph on the baseline
<!DOCTYPE html><style>body, p { margin: 0 } span { color: red }</style><p>ab<span>c</span></p>
---
glyphs 0,12.8 16,12.8 16px rgb(0, 0, 0)
glyphs 32,12.8 16px rgb(255, 0, 0)

=== inline content paints after floats and in-flow blocks
<!DOCTYPE html><style>body, p { margin: 0 }</style><div style="float: left; width: 10px; height: 10px; background: blue"></div><p style="background: yellow">a</p>
---
fill 0,0 800x16 rgb(255, 255, 0)
fill 0,0 10x10 rgb(0, 0, 255)
glyphs 10,12.8 16px rgb(0, 0, 0)

=== right-to-left runs are drawn from their right edge
<!DOCTYPE html><style>body, p { margin: 0 }</style><p>\u05D0\u05D1</p>
---
glyphs 16,12.8 0,12.8 16px rgb(0, 0, 0)

<!DOCTYPE html><style>body, p { margin: 0 }</style><p style="visibility: hidden">a</p>
