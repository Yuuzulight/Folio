=== the body's background paints the canvas when the root has none
<!DOCTYPE html><style>body { margin: 0; background: red } div { height: 10px; background: blue }</style><div></div>
---
fill 0,0 800x600 rgb(255, 0, 0)
fill 0,0 800x10 rgb(0, 0, 255)

=== the root's background paints the canvas and the body keeps its own
<!DOCTYPE html><style>html { background: green } body { margin: 0; height: 10px; background: red }</style>
---
fill 0,0 800x600 rgb(0, 128, 0)
fill 0,0 800x10 rgb(255, 0, 0)

=== borders and rounded corners
<!DOCTYPE html><style>body { margin: 0 } div { width: 100px; height: 50px; border: 2px solid; color: blue; border-radius: 10px; background: yellow }</style><div></div>
---
fill 0,0 104x54 radius 10 rgb(255, 255, 0)
border 0,0 104x54 radius 10 2 solid rgb(0, 0, 255)

=== background-clip padding-box paints inside the border with inner radii
<!DOCTYPE html><style>body { margin: 0 } div { width: 100px; height: 50px; border: 4px dashed red; border-left-color: blue; border-radius: 10px; background: yellow; background-clip: padding-box }</style><div></div>
---
fill 4,4 100x50 radius 6 rgb(255, 255, 0)
border 0,0 108x58 radius 10 4 dashed rgb(255, 0, 0) / 4 dashed rgb(255, 0, 0) / 4 dashed rgb(255, 0, 0) / 4 dashed rgb(0, 0, 255)

=== overlapping radii scale down together
<!DOCTYPE html><style>body { margin: 0 } div { width: 100px; height: 20px; background: red }</style><div style="border-radius: 50px"></div><div style="border-radius: 50%"></div>
---
fill 0,0 100x20 radius 10 rgb(255, 0, 0)
fill 0,20 100x20 radius 50,10 rgb(255, 0, 0)

=== hidden boxes paint nothing but their visible children do
<!DOCTYPE html><style>body { margin: 0 } div { height: 10px; background: red }</style><div style="visibility: hidden"><div style="visibility: visible; background: blue"></div></div>
---
fill 0,0 800x10 rgb(0, 0, 255)
